# MOB-site UI #
## Prerequires ##

- modejs >= 6.x
- grunt-cli
- bower

## Packages ##
Installing bower and grunt-cli globally:
```bash
sudo npm install -g bower
sudo npm install -g grunt-cli
```

## Installation ##

### Sources ####
Downloading UI libs and grunt tools to process them:
```bash
bower update
npm update
```

## Running UI processing ##
Create packed UI site components, copying files.
```bash
grunt
```

Open the site in browser to http://dev.minecraft.of.by
